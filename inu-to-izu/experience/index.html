約1時間で楽しむ

中伊豆 / マス釣り

中伊豆フィッシュファーム

道具を借りて、釣った魚をその場で焼いて食べる体験。

料金
釣りセット2,500円
時間
約1時間（観光情報の目安）
犬の条件
ペット同伴可。大きさ・頭数などの詳細は施設へ確認。

エサ釣り専用・魚のリリース不可。月曜定休、悪天候時は臨時休業あり。

料金・同伴案内 ↗電話で相談

下田 / ロープウェイ・山頂散歩

下田ロープウェイ

寝姿山の散歩とドッグランへ。乗車中はキャリーを使います。

料金
往復：中学生以上1,500円／小学生750円。犬の料金は要確認。
時間
乗車と山頂散歩を含め約1時間
犬の条件
小型犬のみ。室内・乗車時は専用ケージやキャリーバッグ、山頂遊歩道ではリード着用。

階段・坂あり。抱っこだけでの乗車はできません。荒天時は運休あり。

料金・運行時間 ↗犬の条件 ↗

動物や景色を、一緒に楽しむ

東伊豆 / 動物園

伊豆アニマルキングダム

大型犬を含め、犬種・大きさの制限なく入園できます。

料金
来園日別。公式の料金カレンダーで確認。
時間
動物園散策は約1時間半、園全体は約3時間が目安
犬の条件
ワクチン接種証明を持参。伸縮リードは2m以内に固定。

犬と利用できない遊具あり。観覧車は同伴可。展示動物に吠えさせたり、近づけたりしないでください。

日別料金 ↗犬の条件・所要時間 ↗

下田 / 水族館

下田海中水族館

犬を歩かせずに館内を見学。海の動物やショーを楽しむ候補です。

料金
中学生以上2,500円／4歳〜小学生1,250円。犬の料金は要確認。
犬の条件
中小型犬・10kg程度まで。カート・ケージ・バッグを利用。小型犬は抱っこも可。通路に降ろさないこと。

飲食店内への同伴・ペット預かりは不可。イルカとの体験など、すべてのプログラムを犬と利用できるという意味ではありません。

料金・営業時間 ↗犬の入館条件 ↗

中伊豆 / 庭園散歩・鉄道

修善寺 虹の郷

季節の庭園を散策。犬と乗れるロムニー鉄道もあります。

料金
中学生以上1,220円／4歳〜小学生610円。鉄道などは別料金。
時間
園内周遊は約1時間半〜2時間
犬の条件
犬同伴で入園可。入園手続き・利用できる区画は公式の犬連れ案内を確認。
料金・開園日 ↗犬と利用できる場所 ↗所要時間 ↗

伊東 / リフト・山頂散歩

大室山登山リフト

抱っこでリフトに乗り、約1kmの山頂遊歩道へ。

料金
往復：中学生以上1,000円／小学生500円。基準内の犬は無料。
時間
山頂遊歩道の散策20〜30分。リフト・待ち時間は別。
犬の条件
体高45cm以下・体長55cm以下。乗車中は抱っこ、施設内は1m以内のリード。

犬を座席に直接座らせることや、売店への同伴は不可。強風・点検などによる運休あり。

料金・営業時間 ↗犬のサイズ基準 ↗

伊東 / 公園・アトラクション

伊豆ぐらんぱる公園

昼の料金
中学生以上：平日1,600円／土日祝・シーズン1,700円。遊具代・駐車料は別。
犬の条件
昼は1m以内のリード。夜は専用キャリー・カート必須で、抱っこやリードだけでは入園不可。

昼夜入替制。犬と利用できる遊具は当日の運行状況も確認してください。

料金・チケット案内 ↗昼夜の犬の条件 ↗

伊東 / 動植物園

伊豆シャボテン動物公園

料金
中学生以上：平日2,800円／休日3,000円。駐車料は別。
犬の条件
1m以内のリード。バードパラダイス、カンガルーの丘、アニマルボートツアーズなどは同伴不可。

飲食店内は同伴不可、テラス席を利用。必要な予防接種を受けていること。

日別料金・営業時間 ↗同伴できない場所 ↗

自分たちで体験する

下田・外浦 / シーカヤック

KAI’TO 犬とカヤック

犬と同じカヤックに乗って、外浦の湾内へ。4〜10月開催、お盆は対象外です。

料金
大人12,000円／小学生7,000円／犬3,000円。大人1人＋犬1頭なら15,000円。
時間
講習を含め約1時間半。10:00または13:00開始。
持ち物
犬用ライフベストを持参。リード着用、混合ワクチン・狂犬病予防接種済みであること。

日程は要相談。海況・一般予約の状況により受入不可の場合あり。

開催条件・料金 ↗電話で日程・予約相談
