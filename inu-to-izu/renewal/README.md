# 犬と伊豆 再構築・確認版

2026/10/25。既存公開版を残し、`rebuild/dog-izu-20261025` ブランチで制作。

## 構成

- `index.html` / `style.css`：新しい旅行ガイドの画面。
- `app.js`：地域・目的・犬の条件・検索、施設詳細、端末内保存、遅延読み込みの地図。
- `data/spots.json`：施設の唯一の元データ。既存9地域60件と、再確認した追加3件。現在の犬同伴条件を確認できない1件は検索から除外。
- `config.js`：計測・広告の唯一の設定。
- `analytics.js`：イベント送信、同意、所有者除外、確認版の送信禁止。
- `tests/analytics.test.cjs`：計測の境界条件を検証する依存ライブラリ不要のテスト。

この確認版は `noindex`。公開中のファイル、電波マップ、GSCの設定には変更を加えない。

## 情報の扱い

`reviewStatus: reviewed` は2026/10/25に公式・観光協会の掲載情報を再確認した6件。電話・現地確認は未実施。

`inherited` は既存サイトからの移行。新たに確認済みとは扱わない。`pending` のSouth cafeは過去取材情報しか確認できず、通常の検索から除外。

料金・営業時間・犬の条件・確認元・確認日を同じ形式にする。未取得の料金は推測しない。大型犬・屋内設備の絞り込みはタグに記載された条件だけを対象とし、一律の同伴可とは表現しない。

地図は元データに座標がある施設のみ。背景タイルで通信エラーが発生した場合は一覧へ戻り、個別の経路リンクを案内する。画像内にエラーが描かれる等の表示不良にも備え、常設の「地図が表示されない場合は一覧へ」を用意する。位置を推測して埋めない。どの施設からも名前と地域によるGoogle Mapsの経路へ進める。

## 計測

使用するGA4候補は `555642566` / `G-KT9SG4RDYR` の組。既存トップに設置された測定IDに合わせる。接続先に同名のプロパティが他に3件あるが、今回の作業では削除・変更していない。

確認版の `mode: preview` は同意設定に関係なく外部送信しない。実運用の切り替えは、受信確認後に `mode: live` とする。公開URLの移行は別作業。

| イベント | 用途 |
| --- | --- |
| page_view | 同意した閲覧。GA4標準。 |
| filter_change | 地域・目的などの選択。検索文字列は送らない。 |
| view_spot | 施設詳細を開いた回数。 |
| map_open | 地図表示・経路への移動。現在地は送らない。 |
| official_click | 掲載元・施設公式への移動。 |
| save_spot | このブラウザ内の保存・解除。 |
| affiliate_click | A8予約リンクのクリック。予約・売上とは区別する。 |

既存の `inu_to_izu_owner_optout=1` を継承し、所有者を除外。本人同意前・拒否後はGA4を読み込まない。電波マップのパスは計測対象外。

2026/10/25にWindsorから当該プロパティの10/24までのデータ取得に成功。ただしWindsorアカウントはTrialで、期限・継続取得の保証は未確認。GSC Wizardは利用しない。Google Search Consoleの所有権確認ファイルは削除しない。

## 広告

既存のA8広告URLをそのまま引き継ぐ。任意の宿の直リンクを捏造しない。特定の犬宿・地域に直行するようなボタン名を使わず、「じゃらんで宿予約」と案内する。

広告であることを明記し、`rel="sponsored nofollow"` を設定。アフィリエイトクリック数、A8側クリック数、予約件数、承認報酬をそれぞれ別の値として扱う。成果が取得できない場合は未確認とし、0円と断定しない。

2026/10/25に既存A8リンクをHEADリクエスト1回で確認し、HTTP 200でじゃらんトップへ到達することを確認。地域・特定宿・犬同伴プランへの直リンクではない。

**公開前の未完了事項**：A8ログインが必要な提携状態・掲載条件・成果画面の照合。GA4への新イベントの実受信確認。Windsorの試用後の取得経路。移行した既存情報の再確認。代表ページの確認後に、同じテンプレートを既存URLへ展開する。

## 写真

写真とライセンスは画面の「写真の出典」に記載。犬の写真は海外撮影の旅のイメージであり伊豆の写真と偽らない。風景は白浜大浜海岸・大室山の実写。白浜写真を外浦海岸の写真としない。WebP変換・表示トリミングを明記。

## 確認方法

`node --test inu-to-izu/renewal/tests/analytics.test.cjs`

ブラウザではキーワード・地域・目的・大型犬・屋内・再確認済みフィルター、空結果、保存と再読み込み、施設モーダル、地図表示、スマホ幅の横はみ出しを確認する。
